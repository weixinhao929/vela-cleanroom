# 问题记录 · 2026-09-10：视图切换器（Home / Work / Focus）位置"记不住"

> 状态：已修复（同日）。修复要点见文末「修复记录」。

## 现象

用户反馈：左下角的 Home / Work / Focus 悬浮栏每次都要重新调整位置，希望它
能记住上一次设置好的位置。截图中该栏位于主屏左下角、任务栏上方约 125px 处。

## 排查

代码层面位置**本来就有持久化**：`WidgetCanvas.tsx` 的 `useBarDrag` 在编辑模式下
通过把手拖动，落盘到 localStorage 键 `focus-desk.bar-pos.v1`（`persistMirrored`，
随镜像进 SQLite 备份），挂载时同步读回。单看 React 逻辑没有问题。

直接读取运行中安装版（`%LOCALAPPDATA%\Vela\focus-desk.exe`，数据目录
`%LOCALAPPDATA%\com.cleanroom.focusdesk\EBWebView`）的 localStorage LevelDB，
该键的历史值依次为：

| 时间        | switcher        | toolbar          |
| ----------- | --------------- | ---------------- |
| 09-09 18:44 | `{x:0, y:990}`  | `{x:648, y:988}` |
| 09-10 10:06 | `{x:2, y:867}`  | 同上             |
| 09-10 14:01 | `{x:11, y:865}` | 同上             |
| 09-10 14:05 | `{x:0, y:988}`  | 同上             |

再对照本机显示器：

- 主屏 `\\.\DISPLAY5`：1920×1080 @100%，任务栏 48px（可用高 1032）。
- 副屏 `\\.\DISPLAY1`：2560×1440 @150% → 小组件窗口逻辑尺寸 **1707×960**，
  任务栏 48px（可用高 912）。

于是每条记录都能对上号：`y=988` 时栏底 1028，正好贴在**主屏**任务栏（1032）上方
4px；`y=867` 时栏底 907，正好贴在**副屏**任务栏（912）上方 5px。用户的意图
始终一致——在当前看的那块屏上把它贴到左下角任务栏上方——但两块屏的小组件窗口
（`widget-0` / `widget-1`）共用同一个 origin、同一个**全局** key，存的又是**绝对
top-left 像素坐标**：

- 在副屏调好（y≈867）→ 主屏读到同一个值，栏悬在任务栏上方 125px（即截图状态）；
- 在主屏调好（y=988）→ 副屏视口只有 960 高，栏整体落在视口外，**直接消失**
  （截屏副屏实测：小组件都在，切换栏不见）。

于是在哪块屏上调，另一块屏就错位或消失，只能反复重拖。这与
`docs/issues-2026-09-09-multimonitor-and-ddl.md` A 项"设置窗口固定绑定 screen 0"
是同一类根因：多屏数据没有按分区隔离。

次要问题：`onUp` 无论有没有移动都 `persist(last)`，把手仅被点击（例如为了获取
焦点后用方向键微移选中组件）也会把"随任务栏 / 分辨率自适应的默认位置"冻结成
一组绝对坐标，之后再换屏就带着这组坐标跑。

## 修复记录

- 新增 `src/widget/bar-pos.ts`：位置按屏幕分区存储，键
  `focus-desk.screen.<N>.bar-pos.v1`（`N` 来自 `currentScreenId()`，与
  widget-store 其余分区键一致）。`loadBarPos(kind, viewport)` 读取时校验位置
  左上角落在可用视口内（宽 = innerWidth，高 = innerHeight − 任务栏，留 24px
  可抓余量），越界一律返回 null 回到默认位置。本屏尚无记录时一次性把旧全局键
  `focus-desk.bar-pos.v1` 中仍在本屏视口内的条目迁入本屏键，越界条目丢弃；
  迁移后旧键对本屏不再生效（复位不会被旧值复活）；localStorage 不可用或视口
  尺寸异常（0×0）时不落盘迁移，避免误删旧记录。
- `src/widget/WidgetCanvas.tsx`：`useBarDrag` 改用上述模块；新增 3px 拖动阈值，
  纯点击把手不再落盘；`usableViewport()` 统一计算可用视口。
- `src/widget/bar-pos.test.ts`：11 个用例覆盖分区隔离、越界判定、损坏数据、
  旧键迁移（含出屏丢弃 / 复位不复活 / 异常视口不落盘）。
