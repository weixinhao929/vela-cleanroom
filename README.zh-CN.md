# Vela（Focus Desk）

[English](README.md) | 简体中文

基于 **Tauri 2 + React 19 + TypeScript** 的 Windows 桌面效率应用：一层透明、可交互的小组件画布铺在桌面上，把番茄钟、待办、DDL、课程表、习惯打卡、系统监控与媒体控制等日常工具常驻桌面。采用 clean-room 方式实现，不包含任何第三方专有代码。

- 产品名 / 安装包名：`Vela`，版本 `0.1.0`
- 平台：Windows x64（WebView2）
- 许可：MIT（见 [LICENSE](./LICENSE)）

---

### 桌面形态

- **透明小组件层**：无边框、置底、点击穿透——只有控件区域拦截鼠标（Rust 侧命中测试），其余点击直达桌面。
- **组件编组**：编辑模式多选 ≥2 个卡片「编成一组」——带标签条的组容器（`GroupCard`）收纳成员，点标签切换显示；组可整体 8 向缩放（四角 + 四边手柄，键盘 `Shift+方向`）、右键菜单（组配置 / 重命名 / 复制编组 / 置顶 / 移到底层 / 解散与删除整组）；组级与成员级透明度逐级相乘（全局 × 组 × 成员）；成员标签可拖拽重排；解散编组可撤销（快照恢复原位）。编组只是渲染态：成员坐标原样保留，解散即回编组前原位。同类型 ≥2 个实例时标题自动带序号（「时钟 2」）。设置窗侧栏为 视图 → 编组 → 成员 三级树，编组随设置导出/导入整体迁移。
- **添加小组件图库**：画布「+」呼出玻璃模态图库——胶囊搜索、带计数的分类芯片、两列圆形图标卡片；单击卡片即入画布并打勾反馈（图库保持打开，可连续添加），悬停卡片出「入岛」圆钮直接加为灵动岛磁贴。
- **多显示器**：每个物理屏一个 `widget-<i>` 窗口，布局按屏幕独立持久化；显示器热插拔自动同步窗口集合。
- **设置窗口**：独立 WebView（`#/settings`），通用 / 风格 / 显示 / 动效 / 连接 / 灵动岛 / 任务栏 / 更新等页面 + 数据管理；改动实时同步到桌面层。侧栏搜索命中**落到行**：词条定位到具体设置行（滚动居中 + 1.8s 脉冲高亮，懒加载页自动等待渲染），侧栏搜索与命令面板共用同一条跳转信道；语言三档（简体中文 / English / 跟随系统）。
- **速记窗口**：全局热键 `Ctrl+Alt+Q` 呼出，一键写入便签。
- **托盘**：番茄钟控制、备份、新建任务、截图、显示桌面、任务栏外观子菜单、防屏幕捕获（WDA_EXCLUDEFROMCAPTURE：本地可见、录屏/共享不可见，与设置 → 显示 → 隐私同源）、呼出设置。

### 灵动岛（Dock）

贴在屏幕边缘的常驻玻璃条：把常用小组件收成磁贴，点一下就地展开，不占桌面空间。代码标识仍用 `dock`，UI 文案统一为「灵动岛」。

- **入岛三条入口**：① 直接从画布**把卡片拖进岛**——松手默认「添加为磁贴」（画布卡片保留，磁贴绑定该实例，改配置两边同步），按住 `Alt` 松手 = 「移动」（画布实例进回收站，可撤销）；② 编辑模式浮层里的「+」→ 类型选择器（按分类列出全部 33 种类型，顶部搜索按名称 / 描述 / 拼音首字母 / 类型 id 五级评分，命中按全局评分排序——回车即最佳匹配）；③ 「添加小组件」图库里悬停卡片出现的「入岛」圆钮（同类型已在岛上则置灰）。**任何类型都能入岛**，区别只在有无「富形态」。
- **逐磁贴配置**：右键磁贴（或长按 600ms 松手）→ 菜单「配置 / 从灵动岛移除（可撤销）/ 在画布中定位（选中并脉冲高亮）/ 更多设置」；「配置」锚定在磁贴上方的就地弹层，改的是该磁贴绑定实例的配置（无实例则改磁贴私有配置）。
- **岛内排序与移除**：拖动磁贴即 FLIP 重排（等高占位 + 插入位预览），位移 ≤20px 走快档 350ms、跨多行走默认档 500ms；拖出岛 = 移除，弹「已从灵动岛移除 · 撤销」。键盘：`←/→` 在磁贴与「+」间移焦点、`Home/End` 首尾、`Ctrl+←/→` 排序、`Delete` 移除（同样可撤销）、`Enter` 展开、`Esc` 收起。
- **岛位置**：编辑模式下拖岛本体——沿顶边滑动（拖动期只写 transform，松手一次落盘）、靠近左 / 中 / 右自动吸附（阈值 32px）、自由位可用偏移滑条（0–100%）。位置按「岛中心占屏宽比例」存储，换分辨率 / 换屏不跑位；键盘 `Ctrl+Shift+←/→` 依次跳到相邻吸附点。
- **展开与全岛面板**：点磁贴展开该磁贴的沉浸面；**全岛面板**（`dock:panel`）一次看到全部入岛小组件，支持**轮播 / 网格**两种视图。两者与画布卡片的沉浸页共用同一套 `expand-store` 单值互斥框架——同一时刻只有一个展开面。
- **迷你形态**：14 种类型有专属迷你形态（时钟、待办、番茄钟环、系统监控、日历、天气、音乐、习惯、倒计时、通知栈、亮度、剪贴板、秒表、杂项），各自独立 chunk 按需加载；其余类型自动降级为「图标 + 名称 + 一行摘要」的通用磁贴——今日概览 / 截止日期 / 便签 / 回收站 / 快捷方式 / 桌面文件六类高频磁贴的摘要为实时数据（未完成数、条数、根目录名等，随数据源变化自动刷新）。
- **临时接管**：番茄钟响铃 > 亮度 / 音量 / 媒体切歌（同级最新者胜） > 通知到达，同一时刻只显示一条，默认 6s 后回落。亮度 / 音量为应用内调整（画布亮度卡滑杆、音乐卡滚轮调音量）触发的 OSD 式即时反馈；五类接管各有开关、展示时长 3–15s 可调；点接管条会落到对应磁贴（岛上没有该类型磁贴时只回落，不自动添加）。
- **外观与行为**：外形「胶囊 / 贴边刘海」；密度三档（36 / 42 / 48px）；悬停行为「无 / 微涨峰值 / 展开首磁贴」；点击空白 / 中键 / 滚轮可配；自动隐藏「从不 / 全屏应用时隐藏（吃 `presence:state`）/ 空闲 N 分钟后淡出」。
- **显隐与面板热键**：`Ctrl+Alt+I` 显隐本屏灵动岛、`Ctrl+Alt+O` 打开全岛面板，命令行 `--toggle-dock` / `--open-dock-panel` 等价。热键优先由主屏窗口（`widget-0`）响应；主屏被拔除时自动落到现存 slot 最小的窗口（failover）。岛配置按屏独立持久化，多屏各自一条，互不影响。
- **设置入口两处**：① 编辑模式工具栏的「灵动岛」按钮（浮层快捷项：启用 / 贴边 / 位置吸附 + 偏移 / 悬停 / 接管开关 / 磁贴芯片排序与「+」）；② **设置 → 灵动岛** 页（`features/settings/pages/DockPage.tsx`，全量项）。两处读写同一份配置，改动即时按屏落盘（localStorage `focus-desk.screen.<N>.dock.v1` 权威 + SQLite `widget:dock:<N>` 镜像）。
- **数据模型**：`DockConfig` v2（`version: 2`）——`edge` / `offset` / `snap` / `style` / `tiles` / `mouse` / `takeover` / `autoHide` / `panel` / `density`；旧版 v1 载荷（`tiles` 为 `["clock","pomodoro","notifications"]` 这样的字符串数组）在读取时自动无损迁移为 v2 并立即回写。

### 命令行控制面 / 单实例

Vela 由 `tauri-plugin-single-instance` 保证只有一个实例常驻：再次启动 `Vela.exe` 时，第二实例把自己的命令行参数转发给已运行的首实例后立即退出（不会出现双托盘 / 双桌面层）。借此可用 快捷方式或脚本驱动应用（`src-tauri/src/cli.rs`）：

`powershell
Vela.exe --toggle-layer # 显示 / 隐藏小组件层（同 Ctrl+Alt+D）
Vela.exe --show-settings # 呼出设置窗口
Vela.exe --toggle-pomodoro # 开始 / 暂停专注（同 Ctrl+Alt+Space）
Vela.exe --new-task "买咖啡" # 直接创建任务；不带文本则打开新建任务输入框
Vela.exe --toggle-palette # 全局呼出 / 收起命令面板（同 Ctrl+Alt+K）
Vela.exe --toggle-dock # 显示 / 隐藏灵动岛（同 Ctrl+Alt+I，仅主屏响应）
Vela.exe --open-dock-panel # 打开全岛面板（同 Ctrl+Alt+O，层隐藏时先显示）
`

多个参数可同时给出并按顺序执行；未识别的参数被忽略。除 `--toggle-layer` / `--show-settings` 直接操作窗口外，其余开关与全局快捷键走**同一条**分派路径（`shortcuts::dispatch`）。每次转发首实例都会广播 `app:second-instance` 事件（载荷为完整 argv），供 E2E 与可观测性使用。

### 外观与其他

- 2 套内置主题预设（「默认」/「终端」，各带完整深浅两套配色；另有「自定义」档由底色 + 文字色派生，不计入预设数）× 明暗模式（亮/暗/跟随系统），CSS 变量驱动；**主题切换水墨动效**（滴墨晕开过渡，时长 300–3000ms 可调默认 1400，设置 → 风格「主题切换动效」）；壁纸取色后可一键「套用为自定义主题」；**界面缩放**（设置 → 显示，CSS `zoom` 全局生效，拖拽/弹层定位/取色等坐标链路已按缩放系数对齐）；动效三档（增强/标准/减少）+ 逐特效开关 + 空闲淡化卡片（presence Idle ≥60s 时统一降卡片透明度，动一下即恢复），尊重系统「减少动态」。日期/时间与下拉选择均为自绘控件（`DatePicker` / `WidgetSelect`，跟随主题）；下拉统一 glide 交互范式（Glide Select" 自绘：弹出层从触发角缩放淡入、高亮为行间滑行的药丸、换值标签模糊交换、空间不足自动向上翻转、键盘 + typeahead，课程表方案切换与编辑对话框已替换原生 select）。
- **系统监控增强**：网卡选择（最活跃/全部/聚合/指定）、按 bit 计速与简洁模式、上下行交换显示、逐网卡独立趋势曲线（all 模式不再共用全网合计）、网卡连接详情（MAC/IP/网关/链路速率）、本机 TCP 连接列表（含归属进程）、按天流量历史（SQLite 持久化，保留一年，可在 设置 → 连接 关闭流量统计记录以停掉后台采样）+ 网速/日流量阈值系统通知 + 上/下行测速（上行经 Rust 直连不可压缩体，绕过 CORS）；任务栏网速条（贴靠托盘区左侧的独立小窗，经典网速工具 形态）。

## 架构要点

分层与机制摘要见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)；模块级全量说明（目录逐项职责、依赖图、扩展指引）见根目录 [ARCHITECTURE.md](ARCHITECTURE.md)。核心原则：

- **六边形架构**：功能层只依赖 `ports/` 接口，localStorage（浏览器）/ SQLite（桌面）可互换。
- **persist-first 写路径**：先落盘成功再更新内存，失败即上报，杜绝「UI 成功、重启回档」。
- **单一事实来源**：IPC 类型由 Rust models 经 ts-rs 生成；zod schema 与 TS 类型同源；主题 token 由主题引擎独占写入。
- **跨窗口一致性**：事件广播 + 回声抑制 + 叶子级/行级三方合并（以上次交换的快照为共同祖先，并发冲突按 `(ts, json)` 仲裁、两端收敛同一赢家，保留了对端没有的本地值时回播）；恢复备份走暂停-确认-恢复协议。合并比较用**规范化序列化**（对象键按字典序、数组保序）——同一份数据在不同窗口持有不同键序时不再被误判为变更（2026-09-19 修复「设置里快速切换后无限来回切换」同步风暴的根因，见 `docs/issues-2026-09-19-settings-toggle-storm.md`）；分歧回播带指数退避（至 2s 封顶）且保留原编辑时间戳，晚到的水合写入经 `lib/sync-gate.ts` 对广播静默。
- **性能预算内建**：共享采样广播、rAF 节流拖拽、防抖批量化 IPC/写盘、渲染期零副作用等约束在 CI 脚本与单测中固化。
